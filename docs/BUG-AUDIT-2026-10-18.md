# Bug audit: 18 October 2026

This audit used the local working tree based on commit 55c3c10. It did not create production users or change release tags.

## Confirmed defects and local fixes

| Defect | Effect | Fix and evidence |
| --- | --- | --- |
| Translated option labels changed implicit form values | Non-English team creation could fail the server category check; team and map category filters could return no results. Whiteboard controls also contained implicit values. | Add explicit canonical values to category and whiteboard controls. The language layer preserves any remaining implicit option value before translating its label. A DOM regression checks all five languages and selected values. |
| Replacement tokens in dynamic labels were interpreted | A name containing dollar-sign replacement tokens could be displayed incorrectly in a translated call label. | Use a replacement callback so inserted text stays literal. Regression covers three replacement-token forms. |
| Translation lookup inherited object properties | An unknown label such as toString could turn into unrelated text. | Use a dictionary without a prototype. Regression checks unknown object-property names. |
| Group updates rebuilt existing message nodes | Receiving another message removed an open translation and could lose keyboard focus. | Keep existing nodes by message ID and insert only missing messages in sequence order. A mounted group-room regression checks a translated message, focus, and incoming older/newer messages. |

## Validation

- TypeScript and all 22 top-level Vitest checks passed in 48.11 seconds against a disposable local app and isolated fixture databases.
- The localisation script passed six nested tests, including the new language and group-room regressions.
- Documentation and commit-evidence checks passed. They do not prove personal authorship or a completed classmate demonstration.
- The first full run timed out in the animation wrapper. The unchanged animation test passed on its own, and the complete rerun passed. The timeout was not increased and no assertion was removed. This remains a possible test timing issue under load.

## Limits

This is a code and automated-test audit, not proof that the whole product is bug-free. It does not establish current browser layout quality, real microphone/camera behaviour across two devices, restrictive-network call connectivity, or real YouTube playback quality. No production deployment was performed as part of this audit.

## Release follow-up, 19 October 2026

The changes described above remained local after the original audit. They are now being released together: canonical category and whiteboard option values, literal dynamic-label replacement, a translation dictionary without inherited properties, and stable group-message nodes that retain translations and focus. The targeted localisation, English-copy and whiteboard-keyboard run passed nine nested checks against the current code. The complete local suite then passed all 22 top-level checks in 51.27 seconds using an isolated app and disposable databases. Deployment is checked separately from this original local audit record.
